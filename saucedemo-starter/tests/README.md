# Test Suites

- **auth/**: authentication flows across user types and error handling.
- **login/**: detailed login UI validation and credential edge cases.
- **accounts-special/**: behavior for problem/performance/error/visual users.
- **inventory/**: product listing, sorting, and add-to-cart from catalog.
- **product-details/**: detail page data accuracy and cart sync.
- **cart/**: cart contents, badge counts, persistence, and price accuracy.
- **checkout/**: end-to-end purchase flow across all steps.
- **checkout-step-one/**: form validation and navigation from customer info.
- **checkout-step-two/**: totals, taxes, and overview accuracy.
- **checkout-complete/**: confirmation screen and post-order state reset.
- **menu-and-navigation/**: burger menu, logout, and in-app links.
- **footer-and-links/**: footer visibility and external link targets.
- **accessibility-ux/**: titles, focus order, ARIA labels, responsive checks.
- **ux/**: cross-page UI polish and regression checks.
